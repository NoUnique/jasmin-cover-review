# 뒷표지 및 책등 검토

뒷표지 3안은 벡터 객체로 제작했다. 한글 표시 오류를 피하기 위해 웹 검토용 글자는 윤곽선으로 저장했다. 선택 후 Affinity 제작본에는 편집 가능한 문구 레이어를 별도로 유지할 예정이다.

현재는 외표지 디자인 검토 단계이며 판형·제본·용지·쪽수·책등 폭 미확정. 기본 미리보기는 227×300mm, 책등 8mm의 가상 예시이다. 100페이지에서 산출한 값이 아니다. 판형 변경은 화면 비교만 제공하며 최종 판형에 맞춘 재조판은 별도 필요하다. 앞표지 디자인은 기존 선택안의 벡터 재구성본이다.

무선제본 외표지: 뒤 W + 책등 S + 앞 W, 바깥 사방 도련 B. 전체 작업 크기 (2W+S+2B)×(H+2B). 접히는 두 곳에 별도 도련을 더하지 않는다. 양장·날개·스프링 제본은 해당 공식 템플릿으로 다시 설계한다.

최종 내지 PDF의 총 페이지 수(백지 포함), 용지 종류 및 실제 두께, 제본 방식을 인쇄소에 전달하고 받은 책등 값을 그대로 적용한다. 일반적인 추정식은 (페이지 수÷2)×종이 한 장 두께이며 접착제·표지 등 업체 보정은 별도이다. 100p·200p에 특정 두께를 단정하지 않는다.

중요 문구는 재단선과 접힘선에서 기본 10mm 안쪽 배치. 책등 문구는 업체의 최소 두께 및 좌우 안전 여백 조건 확인 후 사용한다. 미리보기는 5mm 이하일 때 문구를 감춘다. 바코드 및 ISBN·출판사·가격·QR의 실제 데이터는 임의 생성하지 않고 확정 후 삽입한다. 뒷표지 하단 우측을 비워두었다. 내측 표지 2면은 현재 범위에 포함하지 않는다.
